AUSTRALIA GRID - CUSTOM REGION ARTWORK
======================================

Put OPTIONAL custom PNG images in this folder.

If a custom PNG exists, the USER Grid Map uses it.
If it does not exist, the live OpenSim composite remains.

RECOMMENDED IMAGE SIZE
======================

1024 x 1024 PNG

Square regions should use square artwork.

You can replace a PNG at any time.
Press CTRL + F5 on the USER Grid Map afterward.

Deleting the PNG automatically restores the live
OpenSim simulator map image.
