# Website usage guide

Use the [installation guide](INSTALLATION.md) first. The [live gallery](SCREENSHOTS.md) follows the approved 34-entry list: 32 verified images and two withheld 3D views. These are fresh captures of the current live website after the DreamGrid 7.2115 update. Personal names, email addresses and private identifiers use capture-only labels. No stored account data, map widgets or failed textures were changed for the images. Grid identity and content shown are examples from the live destination; configure your own installation.

## Public home and login

Open `http://YOUR-GRID-DOMAIN/Other/`, using your installation's actual scheme and web port. The public page offers member login, account creation and Help Centre. Sign in with an existing authorized account. Registration and mail recovery depend on your destination's policy and mail configuration.

## Account, profile and resident tools

ACCOUNT shows current account details and its edit control. PROFILE offers the resident profile tabs and editable fields. REGIONS shows regions available to the signed-in account, with live telemetry and controls. INVENTORY opens inventory browsing and maintenance workflows. IAR BACKUPS shows the current verified archive slots. OFFLINE MESSAGES shows the live delivery queue and friend widget. Screenshots document the ready pages; they do not submit changes, create archives or send messages.

## 2D Map

MAP displays the region texture, navigation controls, layers and Online Now avatar widget. The approved ADMIN and USER images each show a fully loaded FARM SHOP example with a working avatar feed. A zero count is valid when no user avatars are online. A region temporarily unavailable during startup must not prevent other regions from being processed; the next polling cycle retries it.

## 3D Map — screenshots withheld

ADMIN-3D-Map.png and USER-3D-Map.png are withheld because the live 3D scene has unresolved grid-content texture failures. No incomplete 3D image, old capture or substitute texture is presented. Texture repair is outside this website/documentation task. Open the live viewer through 3D MAP. Wait for terrain, geometry, objects, textures and materials to finish before assessing its appearance. The gallery makes no claim that the current scene is fully rendered.

## Administrator tools

MANAGE ACCOUNTS and MANAGE GROUPS show the live directories. CONSOLE provides command/output controls. CONTROL PANEL provides grid operations. STATS shows service health and telemetry; the current screenshot shows Grid login service = RESPONDING. ALL REGIONS shows grid-wide performance. REGION MANAGER shows the region-management table. CREATE REGION opens its blank form. REGION MAP TEXTURES manages region map images. SITE & PAGE DESIGN manages the public and dashboard backgrounds. HELP TUTORIAL PICTURES manages tutorial image slots. These screenshots show the tools without applying configuration changes.

## Page Designer

PAGE DESIGNER opens the visual builder. Its current capture shows the element library, canvas and inspector. Use layouts or add sections, then select an element to edit its content and appearance. Desktop/tablet/phone controls preview the page. Save draft retains work; Publish makes the chosen page available through its public route. Review the builder's checks and tutorials before publishing. No page was saved or published to obtain this screenshot.
