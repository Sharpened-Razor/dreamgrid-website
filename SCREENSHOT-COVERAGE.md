# Screenshot documentation withdrawn

The previous gallery and its images have been removed from the published documentation. It contained incomplete loads, mismatched views/captions and unnecessary duplicate captures.

The replacement set is being recaptured. Each image will require a verified route, active menu, heading, filename and caption; completed dynamic content; a capture manifest; privacy review; and duplicate/near-duplicate review. Screens that fail to load will be recorded as failures instead of published as blank images.
