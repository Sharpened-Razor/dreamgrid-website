Install and configure DreamGrid first. This add-on adapts to your grid.

Required before installation

  • ASCII Windows installation pathEvery folder in the hierarchy must use ASCII characters. Spaces and other drives are supported.
  • DIVA OFFDreamGrid → Setup → Settings → Apache Settings.
  • OTHER enabledSelect/enable OTHER instead of DIVA.
  • Folder = OtherSave, then stop DreamGrid and Apache before installing.

The installer checks these requirements. It does not change your DreamGrid selection silently.

Install in your existing DreamGrid

  1. Install and configure DreamGrid, your grid and regions.
  2. Meet the requirements above and retain the native internal folder layout.
  3. Download the ZIP and checksum; verify the SHA-256 before extraction.
  4. Extract the complete ZIP. Open PowerShell 7 in the folder containing the scripts.
$gridRoot = Read-Host 'Existing DreamGrid data folder containing Settings.ini'
.\Test-DreamGridWebsitePrerequisites.ps1 -Root $gridRoot
.\Install-DreamGridWebsite.ps1 -Root $gridRoot

Start DreamGrid normally after installation. Read the full installation, runtime and rollback instructions →

Required runtimes include PowerShell 7, native Apache/PHP, PHP 7 XML-RPC, Perl on PATH, .NET 8 and the native OpenSim map dependencies. On relocation, rerun the installer with the new root before starting DreamGrid.

Existing content stays yours

Saved pages, images, databases, regions and inventories are preserved. Existing pages are converted only when you choose. Replaced website files receive dated Desktop backups and rollback records.
